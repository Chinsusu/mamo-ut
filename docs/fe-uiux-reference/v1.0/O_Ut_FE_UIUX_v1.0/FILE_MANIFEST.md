# File manifest — O Út FE UI/UX v1.0

## Deliverable chính

- 12 trang public HTML.
- 9 trang admin HTML.
- 2 stylesheet: storefront và admin.
- 4 JavaScript module dạng browser script: dữ liệu demo, component chung, public flow và admin flow.
- SVG icon sprite và bộ ảnh đã đặt đúng vị trí trong UI.
- Zero-dependency local server.
- Laravel-ready view/asset/route scaffold.
- Browser QA, comparison board và báo cáo Design QA.

## Phạm vi cố ý không chứa

- Laravel application/backend hoàn chỉnh.
- Database, migration, model và API thật.
- Authentication/authorization production.
- Cổng thanh toán, vận chuyển hoặc gửi email thật.
- Upload media production.
- Dữ liệu giá, tồn, chính sách, thành phần hoặc tài khoản ngân hàng đã xác nhận.

Các phần trên thuộc bước tích hợp backend, không phải phạm vi FE UI/UX của gói này.
